# 데이터 경계 및 접근 원칙

이 문서는 식탁보 카탈로그(이하 "이 프로젝트")가 다루는 데이터의 범위와, 제3자 서비스에 접근할 때 지키는 원칙을 정리합니다.

## 1. 데이터 성격

카탈로그 메타데이터인 [Catalog.xml](Catalog.xml)과 [sites.xml](sites.xml)은 이 프로젝트가 직접 작성하고 관리하는 자체 자산입니다.

이 데이터는 제3자의 데이터베이스를 복제하거나 파생시킨 결과물이 아닙니다. 각 항목은 기여자가 대상 서비스의 공개된 안내를 확인하여 이 프로젝트의 스키마에 맞게 새로 기술한 것입니다.

설치 파일 자체는 카탈로그에 포함되지 않습니다. 카탈로그는 취득 위치를 가리키는 주소와 실행에 필요한 인수만 기록합니다. 로고 이미지의 취급에 관한 사항은 [TRADEMARKS.md](../TRADEMARKS.md)에서 별도로 다룹니다.

## 2. 취득 경로

설치 파일의 취득은 사용자 환경에서 제공사 서버로 직접 이루어집니다.

이 프로젝트는 제3자 리소스를 대신 내려받아 전달하는 프록시나 중계 서버를 운영하지 않습니다. 카탈로그가 배포하는 것은 주소를 담은 메타데이터뿐이며, 설치 파일의 사본을 보관하거나 재배포하지 않습니다.

사용자 인증 정보는 어떠한 경우에도 이 프로젝트가 보관하거나 경유하지 않습니다.

## 3. 접근 차단 시 대응 원칙

제공사가 의도한 접근을 차단하거나 배포 정책을 변경한 경우, 이 프로젝트는 차단을 우회하지 않습니다.

해당 항목은 다음과 같이 처리합니다.

- 항목을 비활성화하거나 카탈로그에서 제거합니다.
- 자동 취득이 어려운 경우, 이용자가 제공사의 안내를 직접 따르도록 안내 문구로 전환합니다.
- 필요한 경우 제공사에 문의하여 정상적인 취득 경로를 확인합니다.

이 원칙은 기여자에게도 동일하게 적용됩니다. 차단을 우회하는 방식으로 확인한 값을 카탈로그에 반영하지 말아주십시오.

## 4. 인증 및 유료 게이트

로그인, 결제, 회원 등급 뒤에 있는 리소스는 카탈로그의 대상이 아닙니다.

인증 없이 공개적으로 접근할 수 있는 배포 경로만 카탈로그에 기록합니다. 대상 서비스의 이용 자체에 로그인이 필요한 것과, 설치 파일의 취득에 로그인이 필요한 것은 서로 다른 문제이며, 후자에 해당하는 항목은 수록하지 않습니다.

## 적용 범위

이 문서는 카탈로그 데이터의 범위와 제3자 서비스 접근 원칙에 한정하여 적용됩니다. 카탈로그 항목의 정확성과 갱신에 관한 방침은 [CATALOG_POLICY.md](CATALOG_POLICY.md)를 참고해주십시오.
